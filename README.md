# 跨境电商采购订单失败分析

本项目通过历史采购订单识别与采购失败相关的风险信号，并比较两条库存同步预警规则。

## 业务判断

- `is_fulfilled=0` 表示采购失败，`1` 表示采购成功，空值表示尚未回传结果。
- 历史数据表明，库存同步时延是最强的风险信号：时延 0–9 分钟的失败率为 2.59%，10–29 分钟为 29.63%，30–44 分钟为 36.05%。
- 热度 70 分以上的订单失败率高于总体；库存较低的订单风险也略高，但库存量与失败率不是严格单调关系。
- 上述结论是统计关联，不证明单个字段对失败的因果影响。规则上线前应以新的时间段验证，并记录真实的拦截结果。

## 数据口径

- 输入文件：`sourcing_orders.csv`。
- `analyze.py` 每次运行都从原始数据按 `order_id` 保留首条记录，在内存中去重；因此会同时报告重复订单数量，并复现 `sourcing_orders_deduped.csv` 的统计口径。
- 未回传订单不参与失败率、预警命中率、失败覆盖率和误报数计算；但只要触发预警，就会计入预警成本。

## 规则比较

| 规则 | 条件 | 预警订单数 | 命中率（仅已回传） | 已知失败覆盖率 | 理论净收益 |
|---|---|---:|---:|---:|---:|
| A | 同步时延 ≥10 分钟 | 308 | 32.11% | 80.00% | 5360 元 |
| B | 同步时延 ≥10 分钟，且（热度 ≥70 或库存 ≤5） | 113 | 39.09% | 35.83% | 2900 元 |

规则 B 的预警更少、命中率更高，但覆盖的失败更少。本数据和假设下，规则 A 的理论净收益更高；这并不代表规则 B 一定无价值，实际选择还取决于人工复核能力、漏报成本和容忍的预警量。

## 经济价值口径

- 每笔采购失败损失：120 元。
- 每笔预警处理成本：20 元，按所有预警订单收取，包括未回传订单。
- 理论避免损失 = 已知失败命中数 × 120 元。
- 理论净收益 = 理论避免损失 − 全部预警成本。

“理论避免损失”和“理论净收益”假设预警后的复核或拦截可以 100% 避免被命中的失败，属于反事实理论估算，并非已经实现的经营收益。

## 复现命令

在 PowerShell 中执行：

```powershell
.\.venv\Scripts\Activate.ps1
python analyze.py
```

脚本只依赖 Python 标准库，运行后生成：

- `analysis_results.md`：数据质量、总体失败率、各因素分组失败率、规则比较和经济口径。
- `rule_evaluation.csv`：两条预警规则的结构化评估结果。
